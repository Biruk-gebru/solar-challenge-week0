# Notebooks

This directory contains Jupyter notebooks for data exploration and analysis.

## Notebooks

- `<country>_eda.ipynb`: Exploratory data analysis for each country
- `compare_countries.ipynb`: Cross-country comparison analysis

## Usage

1. Activate your virtual environment
2. Start Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
3. Navigate to the notebooks directory and open the desired notebook
